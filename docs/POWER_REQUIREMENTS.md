# ⚡ Power Requirements for Lampy

**Lampy's 72 WS2812B LED strip power consumption:**

- **Minimum:** ~0.5 W @ 1% brightness (~100 mA @ 5V)
- **Maximum:** ~11 W @ 100% brightness (~2.2 A @ 5V)
- **Typical Usage:** ~5-8 W @ 50-75% brightness (~1.0-1.6 A @ 5V)

The above was tested using a USB-C power meter (SATECHI)
